## Коротко о проекте

Демонстрационный игровой проект, в котором библиотека DeBroglie используется для процедурной генерации игрового мира на основе алгоритма Wave Function Collapse (WFC).

Генерация выполняется с использованием образца местности, правил соседства тайлов и заданных частот их появления.

В результате формируется карта с несколькими типами местности:

Равнины (Plains)

Леса (Forest)

Вода (Water)

Горы (Mountain)

Месторождения (Mine)

Полученная карта передаётся игровой симуляции, которая создаёт клетки мира и связанные с ними игровые объекты.

## Версия и подключение библиотеки

В проекте используется DeBroglie 2.0.0.

Библиотека поставляется в виде сборки DeBroglie.dll, предназначенной для netstandard2.0.

Подключение к Unity-проекту выполняется через файл:

Assets/Scripts/Simulation/DragonsAndMachines.Simulation.asmdef

В конфигурации сборки указана внешняя зависимость:

{
    "overrideReferences": true,
    "precompiledReferences": [
        "DeBroglie.dll"
    ],
    "noEngineReferences": true
}

## Архитектура интеграции

Основная интеграция DeBroglie находится в файле:

Assets/Scripts/Simulation/WorldGeneration/DeBroglieWorldGenerator.cs

Генератор реализует интерфейс IWorldGenerator и отвечает за получение карты из библиотеки.

Основной процесс генерации:

Проверяются входные параметры: ширина и высота карты.

Подготавливается образец местности (sampleData).

Создаётся AdjacentModel, который формирует правила допустимого соседства на основе образца.

Задаются относительные частоты появления типов местности.

Создаётся GridTopology с шестью направлениями соседства (DirectionSet.Hexagonal2d).

Настраиваются параметры генерации, включая алгоритм AC-4.

Создаётся TilePropagator, после чего вызывается Run().

При успешном завершении результат преобразуется в WorldGenerationResult.

Полученные значения местности связываются с координатами HexCoord.

После этого WorldFactory использует результат генерации для создания игрового мира.

## Используемые параметры генерации
Для построения модели применяется AdjacentModel.

Правила соседства определяются на основе исходного образца. Поэтому библиотека использует встречающиеся в нём допустимые сочетания типов местности.

Частота задаёт относительное предпочтение при выборе тайла, но не гарантирует точное количество клеток или процент территории определённого типа.

В текущей реализации значения частот задаются в DeBroglieWorldGenerator.cs с помощью SetFrequency() или же через UI.

## Используемый алгоритм и настройки

var options = new TilePropagatorOptions
{
    ModelConstraintAlgorithm = ModelConstraintAlgorithm.Ac4,

    BacktrackType = BacktrackType.Backjump,
    MaxBacktrackDepth = 400,
    RandomDouble = rng.NextDouble,
    IndexPickerType = IndexPickerType.HeapMinEntropy,
    TilePickerType = TilePickerType.Weighted
};

Параметр | Назначение

ModelConstraintAlgorithm.Ac4 | Использование алгоритма AC-4

BacktrackType.Backjump       | Cтратегия возврата при противоречиях

MaxBacktrackDepthс           | Максимальная глубина возврата

RandomDouble                 | Источник случайных чисел

HeapMinEntropy               | Выбор ячейки с минимальной энтропией

Weighted                     | Взвешенный выбор тайла

Генерация запускается методом TilePropagator.Run().

Успешным считается результат со статусом Resolution.Decided.

## Seed и обработка ошибок

Для управления случайностью используется параметр Seed.

Одинаковые исходные данные, настройки и Seed позволяют воспроизводить результат генерации.

В проекте используется следующая логика повторных попыток:

var attemptSeed = unchecked(config.Seed + attempt * 9973);

При неудачной генерации выполняется новая попытка с изменённым Seed. Максимальное количество попыток задаётся параметром MaxAttempts.

После генерации дополнительно проверяется наличие леса, воды и месторождений.

Если результат не соответствует этим условиям или библиотека не смогла получить согласованную карту, генератор возвращает неуспешный WorldGenerationResult с сообщением об ошибке.

## Взаимодействие с игровой симуляцией

После завершения генерации результат передаётся в GameSession.

Основная последовательность:

GameSession.GenerateWorld() вызывает генератор через интерфейс IWorldGenerator.

DeBroglieWorldGenerator возвращает WorldGenerationResult.

WorldFactory.FromGeneration() преобразует результат в состояние игрового мира.

WorldProvider сохраняет созданный мир.

Игровая симуляция использует полученные клетки для размещения зданий и выполнения игровых алгоритмов.

Таким образом, DeBroglie отвечает за процедурную генерацию местности, а игровая логика — за дальнейшую интерпретацию и использование полученной карты.

## Инструкция по запуску

Перед запуском необходимо установить:

Unity Hub

Unity Editor (версия 6000.6.7f1 или выше)

### Порядок запуска:

1. Склонировать публичный GitHub-репозиторий проекта
   
2. Открыть Unity Hub и перейти в раздел Projects

3. Нажать Add -> Add project from disk и выбрать корневую папку проекта

4. Выбрать указанную версию Unity и открыть проект

5. Убедиться, что библиотека DeBroglie.dll находится в каталоге: Assets/Plugins/DeBroglie/

6. Открыть основную игровую сцену, нажав Play

После запуска станет доступна демонстрация игрового проекта с процедурной генерацией мира.

Для проверки генерации можно изменить Seed и повторно запустить создание карты, чтобы сравнить результаты.
